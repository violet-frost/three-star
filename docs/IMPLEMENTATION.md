# 三芒星网页版实现计划

目标：按《游戏策划案》V0.2制作电脑和手机浏览器可玩、可离线打开的单人对三AI完整游戏，交付运行包、全部源码、技术与配置说明。

已确认：使用参考图片的角色造型与配色；网页采用竖屏战斗区域，桌面补充WASD/方向键、1/2/3切阵及空格暂停。无在线匹配或后台服务。

架构：原生JavaScript经典脚本，Canvas2D世界渲染，DOM触控HUD；固定30Hz逻辑、独立60FPS画面。独立配置、几何与规则、模拟、渲染、音频、应用模块。使用经典脚本使index.html可直接通过file协议打开。

视觉：参考图的红金战士、橙红法师、绿衣自然辅助，暖灰石砖、青绿植被、金色星核、紫色暗幕。游戏内地图按正文2400×3200坐标和障碍生成，不将带标注的地图图纸直接当作可行走底图。开始页用原角色图，游戏中使用透明角色图集与程序生成地形。

实现与验证顺序：

- [x] 1. 规则：config.js与rules.js；伤害、承伤、暗幕、排名、碰撞与资源边界自动测试。
- [x] 2. 模拟：simulation.js；中心移动、编队、战斗、阵型效果、死亡批次、野怪、星尘、星核、觉醒、AI、对局结束；固定种子20局与资源守恒回归。
- [x] 3. 表现：render.js与assets；镜头、地砖、障碍、角色、独立血条、弹道、阵型效果、暗幕、飘字与小地图。
- [x] 4. 交互：index.html、style.css、audio.js、app.js；主菜单、教学、摇杆多点触控、键盘、阵型、觉醒、设置、暂停恢复倒计时、观战与结算。
- [x] 5. 交付：README.md、TECHNICAL.md、CONFIG.md、素材说明与工具脚本；桌面1440×1000、触屏390×844、小屏360×640及离线启动验证，生成网页运行包与源码压缩包。

追加需求：随机散落星尘已实现，默认初始80枚、20秒补12枚、地面上限100枚，支持配置。35项自动测试全部通过，包含20局完整模拟；浏览器交互验证无未处理异常。真实手机硬件不在本机验证范围。

V0.3.0：按用户最新表格更新阵型倍率、显示顺序与快捷键，接入镇星全伤害承接、荧惑每第三发双倍火弹、重华每秒最低生命治疗，以及共享新芽治疗图标和对应特效。

验收范围：游戏策划案P0与P1玩法；技术与配置文档。无需交付录像或正式测试报告，但实现过程仍运行必要测试。真实手机硬件与iOS Safari未在本机执行的项目必须如实说明。
