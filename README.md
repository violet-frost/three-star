## 立即体验

**电脑：完整解压后，直接用 Chrome 或 Edge 打开 `index.html`。无需安装依赖、无需联网。**

双击 `启动游戏.bat` 也可以启动：安装了 Node.js 时会打开本地服务器；未安装时直接打开离线网页。请不要仅在压缩包预览窗口中打开HTML，图片和脚本需要保留目录结构。

**手机：**在电脑上运行 `启动游戏.bat`，保持窗口打开，将手机与电脑连接同一Wi-Fi，在手机浏览器输入窗口显示的局域网地址，例如 `http://192.168.1.20:8080`。此方式电脑需安装Node.js；若网络不通，检查两端是否同一网络、访客网络隔离及系统防火墙对该本地服务器的设置。也可把整套网页文件上传任意静态网站服务，通过网址访问。

开发终端可以运行：

```sh
node tools/serve.cjs
```

默认端口8080。可使用环境变量 `PORT` 更改。服务器只提供本游戏目录，没有账户、上传或联网匹配接口。

## 操作

| 行为 | 手机／鼠标 | 电脑键盘 |
|---|---|---|
| 移动整队 | 按住战场空白处呼出摇杆并拖动 | WASD／方向键 |
| 圆阵防守 | 右下第一个按钮 | 1 |
| 楔形进攻 | 右下第二个按钮 | 2 |
| 横阵治疗 | 右下第三个按钮 | 3 |
| 觉醒选择 | 点击一张卡 | 鼠标点击 |
| 暂停／继续 | 右上暂停、继续游戏 | 空格／Esc |
| 全屏 | 电脑侧栏“展开战场” | F |

英雄在射程内自动攻击，移动中也能攻击。阵型承伤、第三发强化及治疗自动生效，无额外技能按钮。支持一根手指拖动摇杆、另一根手指换阵或选择觉醒。

## 当前阵型规则

| 阵型 | 攻击 | 防御 | 中心移动 | 专属效果 |
|---|---:|---:|---:|---|
| 圆阵 | 1.0 | 1.2 | 1.0 | 镇星吸收全队伤害（破阵为承伤标签） |
| 楔形（默认） | 1.5 | 0.8 | 1.0 | 荧惑每3发火焰弹的第3发造成2倍伤害 |
| 横阵 | 0.8 | 1.0 | 1.0 | 重华每秒为当前生命最低的受伤存活队友恢复2点 |

圆阵包含暗幕伤害转移，镇星阵亡后停止代承伤；不会把暗幕减伤。荧惑只累计在楔形实际发射的火焰弹，换阵保留计数。治疗包含重华自身，不超过生命上限、不复活，重华阵亡后停止。旧的分摊、定时蓄能与绊索技能已替换。V0.3.2进一步移除突进、击退、破阵集火及普攻减速，英雄仅执行普通攻击，保留上表阵型效果。

## 地面随机星尘

按用户补充要求，开局随机铺放80枚、四象限均衡分布，每20秒补充12枚，每枚1点，未拾取散落星尘上限100枚。新增位置避开障碍，收圈后只在当前安全区内生成。玩家和AI使用相同的28世界像素拾取半径，拾取同时增加携带和累计星尘，正常触发觉醒。

修改 `src/config.js` 的 `scatter` 配置即可改变数量、间隔、单枚价值、上限和间距；`enabled:false` 可关闭此新增功能。

## 工程结构

```text
index.html              页面入口，直接打开即可运行
style.css               桌面、竖屏手机、HUD与界面样式
src/config.js           全部主要数值、英雄、阵型、地图与觉醒配置
src/rules.js            几何、伤害、排名、随机数、导航
src/simulation.js       完整30Hz对局模拟，不依赖DOM
src/render.js           战场、角色、弹道、特效、暗幕与镜头
src/audio.js            本地合成音乐与游戏音效
src/app.js              输入、界面、状态、暂停、观战、本地保存
assets/                 完整角色图集、竞技场地面与封面
docs/TECHNICAL.md       技术说明、扩展入口与实现边界
docs/CONFIG.md          配置字段与调整示例
docs/ASSETS.md          素材来源、图集格式与生成提示词
tests/                  Node.js原生自动测试
tools/                  本地启动、打包与浏览器验证工具
```

运行包同样附带可阅读修改的JavaScript和配置；完整源码包另包含测试及开发工具。没有压缩混淆，没有付费引擎或构建服务依赖。

## 修改与验证

直接编辑源文件，刷新页面即可生效。推荐Node.js 22或以上运行开发工具；游戏运行本身不依赖Node.js。

```sh
npm test
npm start
npm run build
```

`npm test` 使用Node内置测试运行器，无需 `npm install`。打包脚本另需Python 3。详细说明见技术文档。

## 兼容与实现说明

已使用本机Chrome进行桌面、手机触屏模拟、小屏和离线加载验证；手机触屏模拟不等于真实Android／iOS硬件验证。振动与全屏是否可用取决于浏览器；iOS可能不支持网页振动，不影响游戏规则。手机首次点击后才能播放音频。

本地仅保存音量开关、振动开关、教学标记及近期对局日志，不保存进行中的战斗。清理浏览器站点数据会清除此信息。

美术以用户参考图中的红金镇星、橙红荧惑、绿衣重华及遗迹竞技场为准。游戏角色采用四方向像素图集，配合位移、闪白、死亡消散与程序特效；并非逐项复刻策划案美术资源表中的全部手绘动画帧。
